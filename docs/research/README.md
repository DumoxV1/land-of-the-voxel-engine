# Onderzoeksregister

Elke memo volgt `docs/governance/research-protocol.md`.

## Prioriteiten
1. Filmische openwereldkwaliteit ontleden naar technische, meetbare subsystemen.
2. Micro-voxel datastructuren: blocky, SDF, sparse bricks, DAG/SVO, clipmaps.
3. Renderpaden en clientstack: Godot/GDExtension, Bevy/wgpu, custom Vulkan.
4. Editlatency, physics, AI/nav en persistence op dezelfde werelddata.
5. Authoritative multiplayer, interest management en chunkreplicatie.
6. Benchmarkcontract en minimumdoelhardware.
7. Licenties en herbruikbare open-sourcecomponenten.
