# Architecture Decision Records

Gebruik per blijvende beslissing `NNNN-korte-titel.md` met:

- Status
- Datum
- Context
- Beslissing
- Alternatieven
- Bewijs/benchmarks
- Gevolgen
- Herzieningstrigger

Geen architectuurkeuze wordt definitief omdat één model die adviseert. Minimaal een bron of experiment en een onafhankelijke review zijn vereist.
